# Statistical Survey Analysis with Python

This project was developed as part of an undergraduate Statistics coursework assignment at Ankara University.

The study explores the relationship between future self-clarity and preference conflict using a simulated survey dataset of 480 observations.

## Statistical Methods
- Descriptive statistics and data visualization
- Reliability analysis (Cronbach's Alpha)
- Exploratory Factor Analysis (EFA)
- KMO and Bartlett's tests
- Mann–Whitney U and Kruskal–Wallis tests
- Binary logistic regression
- ROC curve and AUC analysis

## Tools
Python, pandas, NumPy, SciPy, statsmodels, Matplotlib, and factor_analyzer.

## Important Note
The dataset is simulated for educational purposes. Results should not be generalized to real populations.
